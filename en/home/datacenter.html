ERAÜ Data Center

The ERAÜ Radio Communications Networks Committee has modern physical hardware at its disposal. 10Gb/s 44Net network.

 

Private Server or VPS Service

The ERAÜ Radio Communications Networks Committee offers private server hosting services, subject to availability, to qualified amateur radio operators who are also members of ERAÜ.

This is a goodwill service that gives modern amateur radio operators the capability to connect radio waves with the digital world.

Note! To request an ERAÜ private server, please contact help@erau.ee!

Public services

The ERAÜ hosting infrastructure was built so that necessary services would be hosted locally in Estonia and not by a third party. ERAÜ plans to host the digital services required by radio amateurs directly on its own infrastructure.

Examples of currently hosted public services include:

  • Exam test ticket system: ticket.eru.ee
  • NTP Time Server (precise time): ntp.erau.ee
  • LDAP directory service for clubs (via tunnel): erau.local
  • Monitoring platform service (Zabbix, LibreNMS) to keep an eye on repeaters and other infrastructure
  • Computer network service for repeaters using the 44net BGP direct announce interface.

 

44NET

44net (also known as AMPRNet, "Amateur Packet Radio Network") is a worldwide, publicly routable block of IP addresses allocated in the 1980s to licensed radio amateurs globally. It acts as a distinct "internet within the internet"—all devices on this network carry IP addresses starting with the number 44 (within the 44.0.0.0/8 range).

The network is managed by an organization called ARDC (Amateur Radio Digital Communications). Originally, this /8 network block containing 16.7 million IP addresses was allocated to Hank Magnuski (callsign KA6M) for use by licensed amateur radio operators; today, it encompasses more than 12 million IP addresses.

In cooperation with TechnoTLN and EENet, ERAÜ has obtained the 44.30.195.0/24 public IP range from ARDC for use at the TechnoTLN downtown campus.
